# 🌸 VitaTrack

**Votre compagnon santé personnalisé**

VitaTrack est une application web moderne de suivi de santé qui vous permet de :
- 📊 Suivre votre poids et vos mensurations dans le temps
- 🧮 Calculer votre métabolisme basal (BMR), IMC et besoins caloriques
- 🍎 Obtenir vos recommandations de macronutriments personnalisées
- 🌊 Suivre votre biorythme scientifique (physique, émotionnel, intellectuel)
- 🏆 Gagner des points et débloquer des badges
- 📈 Visualiser votre progression avec des graphiques interactifs

## 🚀 Technologies

- **Frontend**: React + Vite + Tailwind CSS
- **Graphiques**: Recharts
- **Backend**: Supabase (PostgreSQL + Auth + API)
- **Déploiement**: Netlify
- **Versioning**: Git + GitHub

## 🛠️ Installation Locale

```bash
# Cloner le repository
git clone https://github.com/VOTRE-USERNAME/vitatrack.git
cd vitatrack

# Installer les dépendances
npm install

# Créer le fichier .env.local et ajouter vos clés Supabase
# VITE_SUPABASE_URL=votre_url
# VITE_SUPABASE_ANON_KEY=votre_cle

# Lancer le serveur de développement
npm run dev
```

## 📦 Build de Production

```bash
npm run build
npm run preview
```

## 🌐 Déploiement

L'application est automatiquement déployée sur Netlify à chaque push sur la branche `main`.
